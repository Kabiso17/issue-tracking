## 問題描述
商家直接上傳手機拍的原圖，常常一張 5～8 MB，商品頁載入很慢。

## 預期結果
上傳時自動壓縮並轉成 WebP，長邊最多 2000px。

## 驗收條件
- [x] 上傳後自動轉成 WebP
- [x] 長邊超過 2000px 會等比縮小
- [x] 保留原始檔一份在 `originals/`，以防要重新處理
- [x] 上傳失敗時顯示明確錯誤訊息
- [x] 有測試

## 脈絡與線索
- 上傳 API：`server/routes/upload.ts`
- 儲存：S3 bucket `shop-product-images`

## 限制
- 不要改前端上傳元件的 UI
